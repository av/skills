## Full Description

**Your agent doesn't just poke around — it follows a 5-phase systematic workflow to find real, reproducible bugs. Every finding comes with exact commands, expected vs actual output, and captured evidence. No false positives, no vague reports.**

### Who this is for
Developers who ship code and want confidence it works. Teams that need automated QA before releases. Anyone whose agent 'tests' things by running them once and saying 'looks good.'

### What your agent learns
- 5-phase workflow: Initialize → Orient → Explore → Document → Wrap up
- Repro-first documentation with exact commands and captured evidence
- Tests happy paths, invalid inputs, missing context, boundary conditions
- Severity classification: Critical, High, Medium, Low
- Aims for 5-10 well-documented issues (depth > quantity)
- Works on CLIs, APIs, backends, and libraries

### Compatibility
Works with any AI agent that reads markdown files: Claude Code, OpenCode, Cursor, Cline, Windsurf, Aider, and more.

### Format
SKILL.md — plain markdown, no dependencies, no lock-in. Drop into your project and your agent picks it up immediately.
