**Turso is what SQLite would be if it were built today. This skill gives your agent complete mastery: CLI shell, JavaScript API, vector search, full-text search with BM25, encryption at rest, MVCC transactions, and change data capture.**

### Who this is for
Backend developers choosing an embedded database. Anyone building with SQLite who wants vector search, encryption, or better concurrency. Developers evaluating database options for edge/local-first apps.

### What your agent learns
- CLI shell (`tursodb`) for interactive queries
- JavaScript/Node.js API (native + WASM)
- Vector search: multiple types, cosine/L2/dot/Jaccard distance
- Full-text search: Tantivy-powered with BM25 scoring
- MVCC concurrent transactions
- Encryption at rest: AES-GCM / AEGIS ciphers
- Change Data Capture for audit logging
- Differences from SQLite: no multi-process, no triggers, UTF-8 only
