## Short Description

## Full Description

**Give your agent a topic and a time limit. It spawns proposer and critic subagents that generate, stress-test, and rank ideas. Stall recovery built in — if ideas plateau, it shifts categories, inverts questions, and changes the critic's lens.**

### Who this is for
Product managers exploring feature space. Developers naming things. Anyone who wants structured ideation, not random suggestions.

### What your agent learns
- Proposer and Critic subagent pairs each iteration
- Clock-governed — runs exactly for the specified duration
- Progress file tracks patterns and scores
- Auto-steers based on critic feedback
- Stall recovery: category shifts, question inversion, lens changes
- Presents top N ideas ranked by critic score

### Compatibility
Works with any AI agent that reads markdown files: Claude Code, OpenCode, Cursor, Cline, Windsurf, Aider, and more.
